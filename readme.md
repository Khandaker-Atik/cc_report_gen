# Population Data Management System

## Overview
This is a comprehensive web application for managing and analyzing population data, built using Python Flask and Tailwind CSS.

## Features
- Population Distribution Calculator
- Random Name Generator
- Child Growth Data Visualization
- Age Group Redistribution Tool

## Prerequisites
- Python 3.8+
- pip (Python package manager)

## Installation
1. Clone the repository
```bash
git clone https://github.com/yourusername/population-data-management.git
cd population-data-management
```

2. Create a virtual environment
```bash
python -m venv venv
source venv/bin/activate  # On Windows, use `venv\Scripts\activate`
```

3. Install dependencies
```bash
pip install -r requirements.txt
```

4. Run the application
```bash
python app.py
```

## Project Structure
- `app.py`: Main Flask application
- `templates/`: HTML templates
- `static/`: Static files (CSS, JS)
- `requirements.txt`: Python package dependencies

## Technologies Used
- Backend: Python Flask
- Frontend: Tailwind CSS
- Data Visualization: Chart.js
- Data Processing: Pandas
